# Contributing to Paper Guanzhi

Thank you for your interest in contributing! This project aims to be the most accurate and comprehensive collection of award-winning CS papers.

## How to Contribute

### Adding Missing Awards

1. **Fork** the repository and create a branch
2. Add entries to the appropriate file under `test-of-time/`
3. **Every entry must include an official source link** (conference website, official blog, or institutional announcement)
4. Submit a pull request with a clear description

### Data Format

Each table entry should follow this format:

```
| Year | **Paper Title** | Author1, Author2 et al. | Venue Year | [🔗](source_url) |
```

### Verification Standards

We prioritize accuracy. Before submitting:

- Cross-check with the **official conference awards page**
- Verify paper titles match the original proceedings (not arXiv versions)
- Confirm author lists against the published version
- Double-check award year vs. paper publication year

### Reporting Errors

Found an error? Please [open an issue](../../issues) with:

- The specific entry that's incorrect
- The correct information
- A link to an authoritative source

### Planned Sections

We welcome contributions to these planned sections:

- **Best Paper Awards** — NeurIPS, ICML, ICLR, CVPR, ACL, KDD, etc.
- **Turing Award** — Key papers by Turing laureates
- **Other Honors** — IJCAI C&T Award, SIGKDD Innovation Award, etc.

## Style Guide

- Use English for all content (paper titles should match original publication language)
- Bold paper titles in tables
- Use `et al.` when author list exceeds 4-5 names
- Keep descriptions concise and factual
- Link emoji 🔗 for source URLs in tables

## Code of Conduct

Be respectful, constructive, and focused on accuracy. This is a scholarly resource — let's keep it that way.
