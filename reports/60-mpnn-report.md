## 历史语境

### 从化学描述符到图上的可学习表示

传统分子性质预测常先构造 Coulomb matrix、Bag of Bonds、指纹或手工对称性函数，再接回归模型。它们能编码领域知识，却把输入表征的能力固定在预先设计的特征上。与此同时，Duvenaud 等人的 molecular fingerprints、Li 等人的 Gated Graph Neural Networks、Kearnes 等人的 molecular graph convolutions，以及 Battaglia 等人的 Interaction Networks 都已在图上执行局部信息聚合。本文 §2 将至少八类模型写成共同的消息、更新、读出接口；作者明确说这是对已有模型共性的抽象，同时再探索新变体，不能把“图消息传递”本身归为他们首创。

### 为什么选 QM9

论文 §1、§4 的 QM9 约有 13 万个小有机分子，以 H、C、N、O、F 构成，最多 9 个非氢原子；每个分子有 DFT 计算的结构与 13 个性质目标。DFT 标签已是量子力学的近似结果，而非高精度实验真值。作者把研究拆成两种输入：有优化后的三维原子位置，以及只有原子和键拓扑。前者可以利用空间距离，后者更贴近未取得构象时的预测场景。论文第 2 页明确说明，对 DFT 标签的误差达到某个“chemical accuracy”估计阈值，仍不等于对实验真值达标。

### 直接前驱

- [Duvenaud 等，2015] 图卷积分子指纹：由原子邻域逐层汇合形成可学习表征。
- [Li 等，2016] GG-NN：按边类型变换邻居状态，采用 GRU 更新；本文以它作为强基线。
- [Kearnes 等，2016] 分子图卷积：显式维护边表示。
- [Battaglia 等，2016] Interaction Networks：消息可同时依赖发送与接收节点。
- [Vinyals 等，2015] set2set：为无序集合构造读出机制。
- [Faber 等，2017] QM9 多种化学表征比较与按目标的误差阈值；本文沿用其数据切分与比较口径。

## 问题形式化

输入是一张分子图 $G=(V,E)$：原子 $v$ 有特征 $x_v$，边或原子对 $(v,w)$ 有 $e_{vw}$，可含键型与三维距离。输出是分子级标量 $\hat y_j(G)$，对应 13 个性质中的第 $j$ 项。作者主要对每个目标分别训练模型，亦试过联合预测。训练把各目标标准化后最小化 MSE；测试报告 MAE 与该目标估计的 chemical-accuracy 阈值 $a_j$ 的比值 $q_j=\operatorname{MAE}_j/a_j$。若 $q_j<1$，仅表示模型相对 **DFT 标签** 的平均误差低于该论文采用的阈值。目标单位、阈值与真实实验测量误差并未被这个无量纲比值抹平。

## 核心方法

### 共同的消息传递接口

论文 §2、Equations (1)–(3) 令初态 $h_v^0=x_v$（必要时填充到维度 $d$），迭代 $T$ 步：

$$
m_v^{t+1}=\sum_{w\in N(v)}M_t(h_v^t,h_w^t,e_{vw}),\qquad
h_v^{t+1}=U_t(h_v^t,m_v^{t+1}),\qquad
\hat y=R(\{h_v^T:v\in V\}).
$$

$M_t$ 产生沿边传递的消息，$U_t$ 更新原子状态，$R$ 从全部原子状态给出分子预测。三者是可学习、可微函数。对分子级输出，$R$ 必须不依赖节点枚举顺序；求和消息及共享参数也必须遵守这一点。正文以无向图介绍接口，实验实现则把化学图当成双向边，分别学习 incoming/outgoing 消息并拼接。各步共享权重，更新器用 GRU（§5）。

### 本文探索的结构变体

- **Edge network（§5.1）：** $M(h_v,h_w,e_{vw})=A(e_{vw})h_w$，神经网络 $A$ 把连续边特征映射到 $d\times d$ 矩阵，使距离与键型影响邻居特征的线性变换。与 GG-NN 对离散边型分别取矩阵相比，它能直接接收向量边特征。
- **Pair message（§5.1）：** $f(h_w,h_v,e_{vw})$ 也读取接收节点；作者试过，但 §8 报告其训练表现较差，不能从一般表达能力推出本实验更优。
- **Virtual edge / master node（§5.2）：** 给未相连原子加虚边，或让每个原子连到共享主节点，缩短传播阶段长程交互的路径。主节点是可学习的全局暂存位置，不等同于一个真实原子。
- **Readout（§5.3）：** 比较 GG-NN 的 gated sum 与 set2set。后者对节点表示集合做顺序不变的聚合。
- **Towers（§5.4）：** 将每节点 $d$ 维状态切为 $k$ 个塔，分别传播后用共享网络 $g$ 混合，降低每塔矩阵运算成本；混合本身仍有开销。

最佳单模型在 §8 被标为 `enn-s2s`：edge network 消息、set2set 读出、显式氢原子以及完整的键型和空间距离。五个验证误差最低模型的集成另标 `enn-s2s-ens5`。不能把集成列的成绩说成单模型成绩，也不能把含空间位置的主结果说成纯拓扑结果。

## 关键公式推导

### 1. 节点重编号为什么不会改变分子输出

**原文依据：** §2，Equations (1)–(3) 与其后“$R$ must be invariant to permutations”。

**补充推导（假设同一函数参数对所有节点共享，邻居按多重集求和）：** 设节点重编号为置换 $\pi$，新图中 $x'_{\pi(v)}=x_v$、$e'_{\pi(v)\pi(w)}=e_{vw}$。初态满足 $h_{\pi(v)}^{\prime 0}=h_v^0$。若第 $t$ 步成立，重编号只改变求和项顺序，因加法交换律有

$$
m_{\pi(v)}^{\prime,t+1}
=\sum_{\pi(w)\in N'(\pi(v))}M_t(h_{\pi(v)}^{\prime t},h_{\pi(w)}^{\prime t},e'_{\pi(v)\pi(w)})
=m_v^{t+1}.
$$

共享更新 $U_t$ 遂使 $h_{\pi(v)}^{\prime,t+1}=h_v^{t+1}$。归纳至 $T$ 后，两图的节点状态集合相同；若 $R$ 对置换不变，$\hat y(G')=\hat y(G)$。这是对**编号**的对称性；不保证对几何旋转、镜像或不同分子构象一概不变。后者还取决于边特征如何定义。

### 2. 局部传播、虚边与主节点的作用范围

**原文依据：** §5.2；§8 Table 3。**补充推导：** 在原图只沿化学键传递的情形，归纳得 $h_v^T$ 至多依赖 $T$ 跳邻域（读出虽可汇集全图，单个原子在传播阶段仍局部）。给不相连的原子对建立虚边后，一次更新即可让它们互通；用主节点则任意两原子可经“原子→主节点→原子”在两次更新内交换信息。路径缩短解释了这些设计的直觉，**不单独证明**准确率一定提高；实际增益需看 Table 3 的实验及其输入口径。

### 3. Towers 的计算量与性能边界

**原文依据：** §5.4，Equation (5) 与其后计算量。**补充推导（假设稠密图、矩阵消息运算主导）：** 原方案每轮近似 $n^2$ 条原子对，每条乘 $d\times d$ 矩阵，代价 $O(n^2d^2)$。分成 $k$ 塔，每塔宽 $d/k$，故传播主项为

$$
k\,O\!\left(n^2(d/k)^2\right)=O(n^2d^2/k).
$$

随后每个原子的 $k$ 个临时状态还需经 $g$ 混合，因此端到端不能简单声称加速 $k$ 倍。论文在 $k=8,n=9,d=200$ 的特定配置报告约 2 倍推理加速；这不是对所有图规模与设备的基准保证。

### 4. 误差比值的正确读法

**原文依据：** §8 与 Table 2。**补充推导：** 若目标 $j$ 的测试 MAE 为 $b_j$，阈值为 $a_j>0$，则 $q_j=b_j/a_j$。$q_j=0.68$ 意味着平均绝对误差约为采用阈值的 68%，不是预测准确率 68%；对不同物理量的 $q_j$ 取平均也不是一个统一的物理误差。因为评价标签来自 DFT，$q_j<1$ 不能推出与实验测量的差低于同一阈值。

## 实验分析

### 设置与主结果

§7 说明使用 130,462 个 QM9 分子，其中随机取 10,000 验证、10,000 测试，其余训练。每个模型与目标组合做 50 次随机超参试验；$T\in[3,8]$，set2set 计算次数 $M\in[1,12]$；Adam、batch size 20、约 300 万步；验证集用于 early stopping 与模型选择。作者称按目标单训通常优于 13 目标联训，部分目标提升可达 40%。实验是同一 QM9 切分下的比较，不能代表跨数据集外推。

PDF 第 8 页（PMLR p.1270）Table 2 中，最佳单模型 `enn-s2s` 的 13 目标平均误差比值为 0.68；五模型集成为 0.52。单模型 11/13 项 $q_j<1$；未达到阈值的是 gap 1.60 与 ZPVE 1.27。五模型集成这两项仍为 1.23 与 1.10。表中还可见相对于已有 GC、GG-NN 与多种手工表征的逐项目标比较。DTNN 仅给出 G 一项且脚注说明数据切分不同，不宜当作完全同设置的全指标基线。

### 消融与输入边界

Table 3 在**无空间坐标**设置下，GG-NN 的平均误差比值 3.47，加入 virtual edge 为 2.90，加入 master node 为 2.62，换 set2set 为 2.57。作者说这些变体的改进覆盖 13 个目标，但表只列平均值，逐项依据在补充材料。Table 4 的 towers8 相对普通 GG-NN，联训平均比值从 1.92 到 1.75，单训从 1.53 到 1.37；作者还说两种训练制式中均有 12/13 项改善。

**非常重要的可用性边界：** §8 明确承认 Tables 3 与 4 使用了 DFT 输出的 partial charge 作为节点输入，在真实应用中预测前通常没有这个特征。Table 2 的主结果没有使用该特征。因此 Tables 3–4 可用于分析结构变体，但不能原样当作“无需 DFT 的上线推理”性能。主模型还用了 DFT 优化结构得到的原子三维位置；仅拓扑实验的数字不能和有空间信息的主表直接互换。

### 作者自述与我的评价

§9 指出大分子外推仍不明朗：原子对距离分布随分子大小变化，全连接消息的入度也变化；作者提出对消息加 attention 只是未来方向。其“QM9 已相当接近解决”的判断有特定前提：小分子、固定切分、DFT 标签、各目标单训及完整空间信息。在我看来，论文最扎实的贡献是统一接口与严格分组的实验，而不是对全部真实化学任务的性能保证。

## 局限性

1. **标签上限：** QM9 的监督信号由 DFT 给出，化学精度阈值与真实实验误差不同；对 DFT 的高拟合质量不能自动变成实验精度。
2. **输入依赖：** Table 2 最佳模型需要三维距离及显式氢；几何位置来自先行的 DFT 优化。没有构象的任务需看 Table 3 的拓扑设置，且该表又用了不能直接部署的 partial charge。
3. **泛化范围：** 最多 9 个非氢原子；没有跨大小、跨化学空间的完整外推检验。全连接距离边的运算与原子对数量近似二次增长。
4. **实验归因：** 不少变体同时改变消息、读出、输入表征与氢表示，Table 2 的最佳成绩不能精确分配给某一个创新组件；50 次超参试验也说明调参预算较大。
5. **有利变体也有反例：** Pair message 不及 edge network，towers 与 edge network 的组合未进一步提升。论文如实报告了这些负结果。

## 后续影响

这篇论文把已有图网络模型放进同一“message/update/readout”语言，并给出分子性质预测的强基准，成为后来讨论 graph neural networks 的常用术语源头之一。这里的“影响”是基于方法沿用的学术判断，不把后续工作的所有提升归因于这一篇。更直接的后续背景可看 Battaglia 等人 [*Relational inductive biases, deep learning, and graph networks*，2018](https://arxiv.org/abs/1806.01261)，其 graph network 视角进一步组织图上的关系计算。本文未取得可核查的同日引用量快照，因此不填引用数字，也不以未经核实的引用数表示影响强弱。

## 个人笔记

我读到第 8 页 Table 3 时，先看到 3.47 降到 2.57，几乎要把它写成“只给化学键也能达到很好的性质预测”。回到同页正文才发现 partial charge 来自 DFT，是预测时尚未拥有的信息。这个细节改变了我对消融实验的阅读顺序：先查输入在应用时能否获得，再看网络结构带来的数值改善。第 3 页那组三行公式很美，但第 8 页这句数据来源说明，决定了公式可以如何落地。

另一个值得留意的点是，局部消息的 $T$ 跳限制与全图读出并不矛盾：读出可以综合所有节点，却不能替单个节点在传播过程中构造它没有看见的远距相互作用。主节点和虚边解决的是传播通路，而 set2set 改的是最终汇总。把两个位置分开，才读得懂 Table 3 各列为何都是“长程信息”的不同入口。

## 小红书写作备忘

### Hook 素材

- 一张分子图：原子互相传递可学习的消息，最后给出一个性质预测。
- Table 2 的 11/13 项低于论文采用的 chemical-accuracy 比值阈值，但两个目标仍未达标。
- Table 3 的结构消融含 DFT partial charge；它解释结构，不等同于独立化学预测的部署数字。

### 核心 Insight

MPNN 用消息、更新、读出三步统一图上的学习；输入是否可在预测时取得，与网络的表示能力同样关键。

### 自查重点

- 不称本文首创图消息传递；区分框架统一、edge network 与其他变体。
- 不把误差比值当准确率；“chemical accuracy”是对 DFT 标签的特定阈值。
- 不把 Table 3/4 的 partial-charge 实验与 Table 2 的无该特征主结果混用；区分单模型与五模型集成。
