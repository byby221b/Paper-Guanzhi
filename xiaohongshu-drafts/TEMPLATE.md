# 小红书论文分享模板 v2

> Paper Guanzhi「AI论文精读」系列。图文笔记，7–9 页轮播图 + 底部文字说明。
> 文风定位：偏学术、含蓄隽永、用词典雅，面向有一定基础的读者。

## 一、标题

```
{论文核心意象的凝练表达}｜AI论文精读 #{期号}
```

要求：
- 克制而有力，不用感叹号、不堆砌情绪词
- 可用古典意象、学术隐喻、精巧的对仗
- 不超过 25 字（不含 emoji 和后缀）

示例：
- 机器能思考吗？——图灵在1950年留下的叩问｜AI论文精读 #01
- 棋盘上的香农：信息论之父的另一面｜AI论文精读 #02
- 从152层残差网络到一个跳跃连接的顿悟｜AI论文精读 #55

## 二、轮播图分页结构（7–9页）

### Page 1 — 封面

由 ImageGen 生成，统一视觉风格：
- 深藏青底色，细金线构图
- 论文标题（英文原名）、作者、年份
- 核心概念的极简示意图
- 右上角「AI论文精读 #XX」角标
- 左下角「Paper Guanzhi」水印
- 尺寸：1024×1280（4:5 竖版）

### Page 2 — 作者与论文（约 150–180 字）

介绍作者学术身份、师承关系、当时所处的学术环境；
点明论文发表的时间、刊物、及其在学术谱系中的位置。

```
✍️ 作者

Peter Hart、Nils Nilsson、Bertram Raphael，
三人彼时同在斯坦福研究院（SRI International）。

Nilsson 后来成为斯坦福 AI 实验室主任，
著有《The Quest for AI》——本系列的重要参考文献之一。

📄 论文

A Formal Basis for the Heuristic Determination
of Minimum Cost Paths
IEEE Trans. SSC, 1968

这篇论文不到 10 页，却为整个启发式搜索领域
奠定了数学根基。
```

### Page 3 — 问题的提出（约 150–180 字）

以精炼的语言勾勒时代背景与问题本质。
可以用一个精当的比喻点明困境，但不刻意"接地气"。

```
🔍 问题

1960年代，人工智能的核心任务之一是搜索——
在指数级增长的状态空间中寻找最优路径。

彼时的算法面临一个两难：
广度优先搜索（BFS）保证最优，但穷举代价高昂；
贪心搜索凭借启发信息大幅剪枝，却无法担保全局最优。

效率与最优性，似乎是鱼与熊掌。
```

### Page 4 — 前人的困境（约 120–150 字）

简述此前方法的局限，交代学术脉络中的未解之处。
语气审慎，不贬低前人，而是指出问题的深层原因。

```
📜 前人之困

Dijkstra（1959）给出了无启发式的最优搜索，
但它对每个节点一视同仁，在大规模图上效率不彰。

启发式方法（如 Best-First Search）虽快，
却缺乏最优性的理论保障——
没有人知道，什么样的启发函数才是"安全"的。

问题的症结在于：尚无一个统一的框架，
能严格刻画启发信息与搜索最优性之间的关系。
```

### Page 5 — 核心思想（约 180–220 字，本篇灵魂）

阐释论文的核心洞见。允许出现一个关键公式，
但须以精准而非冗余的方式加以阐释。

```
💡 A* 的洞见

Hart 等人提出的评价函数：

    f(n) = g(n) + h(n)

g(n) 是起点到节点 n 的已知代价——这是事实；
h(n) 是 n 到目标的启发式估计——这是判断。

关键定理：若 h(n) 始终不超过真实代价
（即 admissible，可容许的），
则 A* 必然找到最优路径，
且在同类算法中扩展最少的节点。

这一结论的精妙在于：
它将「什么样的直觉是可靠的」这一模糊问题，
转化为一个可验证的数学性质——可容许性。

从此，启发式搜索不再是经验之谈，
而有了坚实的理论根基。
```

### Page 6 — 主要贡献（约 150–180 字）

列举论文的学术贡献，措辞严谨，突出原创性。

```
🏛️ 贡献

· 首次给出启发式搜索的最优性与完备性证明
· 提出 admissibility 概念，
  为启发函数的设计提供了判据
· 证明了 A* 的节点最优展开性质：
  任何同等条件下的算法不可能更高效
· 统一了盲目搜索与启发式搜索的理论基础

这篇论文之后，搜索不再是 AI 的「技艺」，
而成为了一门「科学」。
```

### Page 7 — 历史回响（约 120–150 字）

论文发表后的影响、在学术史上的地位、当代的回响。

```
🕰️ 回响

A* 发表近六十年，其影响远超 AI 搜索领域：
GPS 导航、游戏寻路、机器人路径规划、
编译器优化……处处可见它的身影。

Google Scholar 引用逾 12,000 次。
IJCAI 将其列为 AI 领域最具影响力的论文之一。

更值得深思的是：在深度学习主宰一切的今天，
A* 依然是许多问题上的最优选择。
真正的经典，不因范式更迭而褪色。
```

### Page 8 — 精读手记（约 150–200 字）

从精读报告「个人笔记」中提炼一条最有洞察力的感悟，
以第一人称视角呈现，展现深度阅读后的私人思考。
与其他页的学术叙述形成对比——这一页更私人、更具体、更有温度。

要求：
- 来源必须是精读报告中的真实阅读体悟，不可凭空编造
- 允许稍微主观，但仍须有论文内容支撑
- 避免泛泛而谈，必须指向论文中某个具体段落、公式或论点
- 语气可从「学术随笔」略微松弛为「读书笔记」

```
📝 精读手记

读这篇论文最让我意外的，
是第七节关于「学习机器」的讨论。

图灵不仅建议从「儿童机器」开始训练，
还指出了「惩罚–奖励」机制和「突变–选择」的类比。

1950 年，没有任何 AI 系统可供参考，
他凭纯粹的逻辑推理预见了
七十年后强化学习与架构搜索的核心思路。

有些论文的价值在于解决问题；
这篇论文的价值在于，
它在问题尚未出现时就勾勒出了答案的轮廓。
```

## 四、文风规范

- 总基调：学术随笔。严谨而不枯燥，典雅而不掉书袋
- 叙述节奏：起笔可有文学性的勾连，中段进入学术分析，收束回归历史视野
- 术语处理：英文术语首次出现时附中文译名或释义，此后可直接使用
  （例：「admissible（可容许的）启发函数」）
- 公式：每篇最多 1–2 个核心公式，配以精准阐释而非冗余翻译
- 禁忌：不用"离谱""绝了""家人们"等网感词汇；
  不用感叹号制造兴奋感；不使用反问句堆砌
- 段落：每段 2–4 行，段间留白，呼吸感充足
- 列举：用 · 号，每条一句话或两短句，不做长段展开

## 五、学术准确性检查清单

以下六类问题源自实际稿件审校，是科普写作中最常见的「说得过满、过直白」陷阱。
每篇草稿完成后，须逐条对照自查。

### 1. 绝对化归因

**典型错误**：「X 单枪匹马地创立了某领域」「X 首次提出了 Y」
**修正原则**：除非有学界公认的唯一归属，否则使用「开创」「系统阐述」「率先将……形式化」等留有余地的表述。对「首次」「唯一」「最早」类断言，须有文献佐证。

### 2. 理论表述不严格

**典型错误**：「博弈论已经证明每个局面都有确定的结果」
**修正原则**：区分「定理的精确陈述」与「通俗转述」。若需简化，加限定词（「在有限确定性完全信息博弈的条件下」）而非直接略去前提条件。引用定理时，宁可多写一个从句交代前提，也不可图简洁而失严格。

### 3. 公式解读臆造

**典型错误**：对公式中的变量赋予想当然的含义（如将评价函数中的权重 K=200 解释为「失去王意味着一切结束」）
**修正原则**：公式解读必须忠于原文。如果原论文未解释某个参数的设计意图，只描述其功能（「评价函数将子力优势与若干局面特征合并为一个分数」），不做主观推演。**宁可少说，不可错说。**

### 4. 贡献描述过满

**典型错误**：「首次将 minimax 原理工程化」「引入了 quiescence 的概念」
**修正原则**：区分「提出」与「系统阐述」，区分「引入概念」与「提供了后来概念的思想前身」。用词梯度参考：
- 最强：提出 / 证明 / 创立（需确凿证据）
- 中等：系统阐述 / 形式化 / 给出框架
- 最弱：预见 / 启发 / 提供了……的重要前身

### 5. 后续影响夸大

**典型错误**：「此分类框架沿用至今」「已成为计算复杂性理论中的标准参考」「本质上是 Type A 策略的极致工程实现」
**修正原则**：影响描述须限定范围和程度。
- 「沿用至今」→「深刻影响了后来的……研究」
- 「标准参考」→「最常引用的经典数字之一」
- 对后续系统（如 Deep Blue、AlphaZero）的描述，须提及其区别于原始方法的关键技术细节，不可简化为「本质上是 X 的实现」。例如 Deep Blue 不仅是 Type A 搜索，还包含 alpha-beta 剪枝、自定义硬件和领域启发式；AlphaZero 是用神经网络引导的 MCTS 替代了手工评价函数与 alpha-beta 搜索。

### 6. 细节省略不当

**典型错误**：「图灵在一本哲学杂志上……」（未指明刊名 *Mind*）
**修正原则**：提及期刊、会议、机构时，首次出现须给出具体名称。读者若想查证原文，模糊的指代会造成不便。当信息唾手可得时，省略反而显得不够严谨。

### 7. 头衔与身份须有出处

**典型错误**：写出具体职务名称（如「某某实验室副主任」）但无一手文献佐证。
**修正原则**：人物的具体职务、头衔必须可溯源。若无法确认，用功能性描述替代（「并参与当地早期计算机研究工作」），不编造精确头衔。**错误的精确不如正确的模糊。**

### 8. 主观评价伪装为事实

**典型错误**：「最有力的哲学挑战」「最重要的贡献」
**修正原则**：评价性判断须加降级词。「最有力」→「最著名的……之一」；「最重要」→「影响最为深远的……之一」。或改用可验证的客观指标（引用数、获奖记录等）。

### 9. 不同指标不硬对齐

**典型错误**：论文 A 定义的指标是「审问者正确识别率不超过 70%」，草稿中写成「被判为人类的概率达到 73%」后直接说「达到了原文预言的阈值」——两个指标的定义方向不同。
**修正原则**：引用数据做比较时，须确认两侧指标定义一致。若不一致，用模糊连接（「与……的经验性预测已相当接近」）而非等号。
